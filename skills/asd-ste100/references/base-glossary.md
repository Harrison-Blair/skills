# STE glossary

This is the user-level base glossary. It applies to every project. A project glossary (`STE-GLOSSARY.md` at the repository root) adds terms and overrides this file. A word that a project defines as a term is never banned.

| Term | Meaning | Do not use |
| --- | --- | --- |
| agent | A model process that acts on instructions. | bot, assistant |
| user | The person who gives instructions to an agent. | customer, client |
| harness | The program that runs an agent, such as Claude Code, Codex, or Pi. | |
| skill | A directory with a `SKILL.md` file that gives an agent instructions for one kind of task. | |
| check | Compare a result with an expectation. | confirm, validate |
| verify | Check completed work independently and record the result. | |
| start | Make a process or session begin. | initiate |
| stop | Make a running process end. | halt, terminate |
| remove | Make an item no longer exist. | erase |
| fix | Change code or text so that a defect does not occur. | repair |
| use | Apply a tool, command, or value for a purpose. | utilize, employ |
| change | Make something different. | modify, alter |
| get | Read a value from a source. | retrieve, fetch, obtain |
